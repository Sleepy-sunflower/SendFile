# 邻传 SendFile

在同一局域网里，两台设备用浏览器打开同一个网页，即可互相传文件。

仓库：https://github.com/Sleepy-sunflower/SendFile

## 这个仓库是怎么做出来的

用 Cursor 从零搭的一个小工具：一台电脑跑 Node.js 服务（`server.js`），同时提供网页和 WebSocket 中转。前端是原生 HTML / CSS / JS，无框架、无 npm 依赖。

文件不会存到磁盘，而是由发送方切成小块，经这台电脑转给接收方。没有用 WebRTC：局域网 `http://` 不是安全上下文，浏览器里往往用不了。

## 功能

- 本机启动后，把局域网地址发给另一台设备，用浏览器打开即可
- 在线设备列表，点选对方后拖拽或选择文件发送
- 显示进度；收到后可保存到本地
- 电脑、手机浏览器均可（需能访问这台电脑的 3000 端口）

启动：

```bat
node server.js
```

需要 Node.js 18+。Windows 也可双击 `start.bat`。

## 局限性

- 必须有一台电脑一直开着这个服务；对方访问的是这台电脑的 IP，不是公网
- 设备之间要能互通。很多校园网 / 公共 Wi-Fi 开了 AP 隔离，互相 ping 不通，这个应用也用不了；可改用同一个手机热点或家用路由器
- 不能跨互联网传输
- 文件在浏览器内存里拼起来，过大可能卡顿或失败
- 同一台电脑多开几个标签页，会被当成多个「用户」（地址往往是 `127.0.0.1`）
